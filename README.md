# Scoop bucket for Mothball

```powershell
scoop bucket add mothball https://github.com/herocodess/scoop-bucket
scoop install mothball/mothball
```

This installs the portable build: the app, `mothball` on your PATH, and a Start menu entry. To start Mothball in the background at login, run `mothball service install`.

Prefer the regular installer (updates itself, starts at login by default)? Download it from the [latest release](https://github.com/herocodess/mothball/releases/latest).
